assertMessageQueueContains (assert message queue contains message)

Syntax:

assertMessageQueueContains( userOrQueue : library : msgId : msgText : msgHelp : sinceTime );

Description:

Checks whether a given message queue contains a message, that has been sent since sinceTime. The message is identified by any combination of ID, message text or message help and must match all specified selection parameters. Unused selection parameters must be omitted (*omit).

userOrQueue and library specify the message queue. If library is omitted, userOrQueue is the name of a user profile, whose message queue is searched.
Message ID can be set to *EMPTY to test that no message has been sent to the message queue since sinceTime. All other selection parameters must be omitted.
Message text and message help can be specified as generic strings with * at the beginning and/or at the end, e.g. Order*, *processed or *Order*. The comparison is not case-sensitive. At most the first 4096 characters of the message help are compared.
Messages sent before sinceTime are ignored. The value of sinceTime should be created with getFullTimeStamp().

Return value:

void

Example 1: 

testStartTime = getFullTimeStamp();
// run the test, that is expected to add the message to the message queue
assertMessageQueueContains( 'QMSGQT' : 'QTEMP' : *omit : 'MSGQT - iRPGUnit' : *omit : testStartTime );

Example 2: 

testStartTime = getFullTimeStamp();
// run the test, that is expected to add no message to the message queue
assertMessageQueueContains( 'QMSGQT' : 'QTEMP' : '*EMPTY' : *omit : *omit : testStartTime );
